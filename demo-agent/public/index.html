OpenBox × OpenRouter

an @openrouter/agent run, governed end to end — every decision below came from Core

Each row is one governed activity: the model calls and every tool, with the verdict Core returned. A policy on this agent decides them — attach one and a refund_order row turns BLOCK or HALT, or waits on REQUIRE_APPROVAL while a human decides. The tool body never runs unless the verdict allows it. The routing preflight row is the same decision made one step earlier: it is evaluated before the request leaves the process, so a CONSTRAIN there rewrites where the prompt may go — and a refusal means it was never sent at all. The line at the end of a run is OpenRouter's own record of where it actually went.
